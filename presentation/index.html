Pillow Scripts

The classic PIL command-line utilities & Tk demos,
kept alive for the Pillow era

pip install pillow-scripts · github.com/python-pillow/pillow-scripts

What is it?

  • A collection of "more or less trivial utilities and demo programs"
  • Originally shipped with PIL by Fredrik Lundh (1995–2003)
  • Lived in the main Pillow repo until December 2017
  • Split out from Pillow@9fcc58d into its own package
  • Every Scripts/*.py is installed onto your PATH
Pillow core no longer ships these; this repo preserves them as a separate PyPI package.

pilconvert 0.5 · 1998

Convert between any formats Pillow understands


# format inferred from the extension
pilconvert.py photo.tiff photo.png

# greyscale, optimized JPEG at quality 85
pilconvert.py -g -o -q 85 photo.png photo.jpg

# list supported formats
pilconvert.py -f

-c format · -g grey · -p palette · -r RGB · -o optimize · -q quality

pilfile 0.4 · 2003

Identify image files: format, size and mode


$ pilfile.py *.png
logo.png: PNG 512x512 RGBA
icon.png: PNG 32x32 P

# verify headers, show info + tile data
$ pilfile.py -v -i scan.tif

-f formats · -i info · -v verify · -q quiet

pilfont 0.4 · 2002

Compile X11 BDF and PCF fonts into PIL raster fonts


pilfont.py "fonts/*.bdf"
# -> writes .pil + .pbm pairs for ImageFont.load()

pilprint 0.3 · 2003

Render images to PostScript via PSDraw


# PostScript to stdout
pilprint.py photo.jpg > photo.ps

# colour, straight to a named printer via lpr
pilprint.py -c -P office photo.jpg

-c colour · -d debug · -p lpr · -P printer

pildriver

An image-processing calculator by Eric S. Raymond

  • A stack machine — Polish (prefix) notation
  • Tokens are pushed, then evaluated right-to-left
  • Run with arguments, or interactively as a REPL
  • Deliberately doesn't catch exceptions: errors are diagnostics

Reading right to left


# open test.png, crop the top-left corner, show it
pildriver.py show crop 0 0 200 300 open test.png

# open test.tiff, rotate 30°, save as PNG
pildriver.py save rotated.png rotate 30 open test.tiff

# interactive
$ pildriver.py
pildriver> verbose 1
pildriver> thumbnail 128 128 open big.jpg

Trick from painter.py

Tk repaints the whole PhotoImage on every paste — so split it into tiles


self.tile = {}
self.tilesize = tilesize = 32
xsize, ysize = image.size
for x in range(0, xsize, tilesize):
    for y in range(0, ysize, tilesize):
        box = x, y, min(xsize, x+tilesize), min(ysize, y+tilesize)
        tile = ImageTk.PhotoImage(image.crop(box))
        self.create_image(x, y, image=tile, anchor=tkinter.NW)
        self.tile[(x, y)] = box, tile

make_hash

The newest script (2021) — a helper for Pillow's C core

  • Brute-forces a collision-free hash table for the 21 image modes
  • djb2 variant: multiply by 33, XOR the character
  • Emits ACCESS_TABLE_SIZE and ACCESS_TABLE_HASH

def hash(s, i):
    # djb2 hash: multiply by 33 and xor character
    for c in s:
        i = (((i << 5) + i) ^ ord(c)) & 0xFFFFFFFF
    return i
